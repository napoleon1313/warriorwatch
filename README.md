# WarriorWatch

Live and historical occupancy for University of Waterloo athletics facilities (PAC and CIF), with typical-crowd curves, "best time to go", facility hours for all 44 spaces, and a public JSON API.

Data source: the public UWaterloo Athletics member portal (`warrior.uwaterloo.ca`). Not affiliated with the University of Waterloo or Warriors Athletics.

See `docs/PLAN.md` for the build plan and `packages/contract/` for the data contract and API.
